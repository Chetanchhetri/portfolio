# 🚀 Personal Portfolio & Showcase

A modern, responsive, and performant developer portfolio built to showcase my projects, technical skills, and professional experience.

![Portfolio Preview](https://via.placeholder.com/800x400?text=Portfolio+Preview+Screenshot)

---

## 🛠️ Tech Stack

* **Frontend:** React / Next.js, Tailwind CSS, Framer Motion
* **Languages:** TypeScript, JavaScript, HTML5, CSS3
* **Deployment & Hosting:** Vercel / Netlify
* **Analytics & Tools:** PostHog, Lucide Icons, VS Code

---

## ✨ Key Features

* 📱 **Fully Responsive:** Smooth experience across mobile, tablet, and desktop viewports.
* 🌙 **Dark / Light Mode:** Dynamic theme toggling with system preference detection.
* ⚡ **Performance Optimized:** Fast page loads, optimized image assets, and excellent Lighthouse scores.
* 🎨 **Interactive UI:** Smooth page transitions, micro-interactions, and motion effects.
* 📬 **Contact Form:** Integrated serverless email handling for instant inquiries.
